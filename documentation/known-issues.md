| 50 | **The real cause of `error: loader/efi/linux.c:grub_cmd_linux:700:premature end of file`.** GRUB 2.16 reads btrfs files block by block and stops at the last *whole* block: a file whose size is not a multiple of 4096 has its final partial block in a tail extent (`last,shared`/`last,eof` per `filefrag -v`) that GRUB's driver skips. ## Security notes

- Live session has a known password (`live`) and passwordless sudo; this is
  **live-only** and removed by `99-cleanup.sh`, which fails the install if the live
  user or sudoers rule survives.
- The firewall is enabled post-install with deny-incoming, nothing allowed.
- No AUR builds as root; the ISO carries prebuilt local packages only.
