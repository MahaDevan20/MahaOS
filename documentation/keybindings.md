# Keybindings

The user-facing list is **generated** and shipped inside the image at
`/usr/share/doc/mahadevanos/shortcuts.md` (open it with `mhelp keys`, or from the
"Shortcuts" entry in the launcher). It is not maintained here: a hand-written copy
in this repository would drift from the compositor configuration, which is exactly
what happened before 2026-11-23 (`documentation/known-issues.md` #27).

Source of truth: `configs/hypr/hyprland.lua` (Hyprland 0.57 reads the Lua config;
a `hyprland.conf` is ignored). **Super is the Windows key.**

```bash
# Regenerate the shipped sheet (also run by scripts/build-repo.sh)
./scripts/gen-shortcuts.sh

# Fail if the committed copy and the config disagree
./scripts/gen-shortcuts.sh --check
```

`scripts/gen-shortcuts.sh` fails when a `hl.bind()` in the config has no line in
`configs/hypr/shortcuts.tsv`, or when a line describes a bind that no longer
exists, so adding or removing a key cannot leave the documentation behind. The
static sections (live-only key, TTY escape hatches, mouse gestures, kitty
shortcuts) live in `configs/hypr/shortcuts-extra.md`.

What the sheet must always cover, and does:

| Area | Example entry |
|---|---|
| Terminal | `SUPER + Q` opens kitty |
| File manager | `SUPER + E` opens Dolphin |
| Launcher | `SUPER + D` opens wofi |
| Closing a window | `SUPER + C` |
| Workspaces | `SUPER + 1..0` switch, `SUPER + SHIFT + 1..0` move a window |
| Focus and moving windows | `SUPER + arrows`, `SUPER + SHIFT + arrows` |
| Resizing | `SUPER + right-drag`, `SUPER + <loop>` floating/tiling keys |
| Fullscreen / floating | `SUPER + F`, `SUPER + Space` |
| Screenshot | `SUPER + SHIFT + S` (region), `SUPER + PRINT` (screen) |
| Lock screen | `SUPER + SHIFT + L` |
| Volume / brightness | `XF86Audio*`, `XF86MonBrightnessUp/Down` |
| Reload the config | `SUPER + SHIFT + R` (`hyprctl reload` from a TTY) |
| Exit Hyprland | `SUPER + SHIFT + Q` |
| Escape hatch | `Ctrl + Alt + F2` … `F6` for a text console; **labwc** in SDDM |

## Verifying that Hyprland actually loaded this config

`tests/install/gui-install-test` (`scripts/test-install-gui.sh`) drives the live
session: it sends `Super + Q`, requires kitty to open with the `mhelp` hint (so the
shipped binds are in effect), types `mhelp keys` in that window, and after the
install checks the live Hyprland log for an autogenerated-config warning.
`tests/docs/check-learning.sh` checks the generated sheet against the config
without a VM.
